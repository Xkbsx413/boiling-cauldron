# 沸鼎烟火 · 核心玩法设计记录

主题：麻辣烫 / 钵钵鸡
记录日期：2026-10-25

## 1. 底料与汤底（炒锅配方）

- 优先实现：通过森罗厨房的炒锅配方制作相关底料、汤底物品。
- 使用森罗的炒锅配方类型 `kaleidoscope_cookery:pot` 注册。
- 三种底料产物均为 1 个，且都是可手持物品。
- 状态：物品、配方、标签、纹理已实现。
- 配方：
  1. 菌菇底料 = 大蒜 x1 + 竹荪 x1 + 原版蘑菇标签 x2 + 油脂块 x1 → 菌菇底料 x1
  2. 麻辣底料 = 花椒 x1 + 森罗辣椒 x1 + 大蒜 x1 + 油脂块 x1 → 麻辣底料 x1
  3. 藤椒底料 = 花椒 x2 + 大蒜 x1 + 油脂块 x1 → 藤椒底料 x1
- 使用构想（暂不实现）：1 个底料放入锅里，可以制作 128 个物品。
- 实现备注：
  - 油脂块使用 `kaleidoscope_cookery:oil_block`，并加入 `kaleidoscope_cookery:pot_ingredient` 标签，使其能作为炒锅配料放入。
  - 1 个油脂块由 9 个油脂合成；此外森罗炒锅开炒前仍需先抹 1 个液体油脂（`#kaleidoscope_cookery:oil`），这是锅的独立状态。
  - 森罗辣椒建议使用 `c:crops/chilipepper` 标签（红辣椒 / 青辣椒均可）。
  - 原版蘑菇标签 `boiling-cauldron:mushrooms` 包含红蘑菇和棕色蘑菇，配方中需要 2 个该标签材料。
  - 无容器的炒锅成品需要潜行并使用锅铲取出，底料沿用此机制。

## 2. 钵钵鸡（冷泡）

- 容器中放入冷水 + 底料。
- 浸泡一段时间。
- 到时后可以用碗取出。
- 竹签：可以考虑注册一个竹签物品，是否使用待定。
- 食用效果与麻辣烫分开定义。
- 待定：
  - 容器方块形态（钵 / 盆）与容量。
  - 取餐方式：碗取还是竹签串取。
  - 是否支持多人取用。
  - 浸泡时长与是否需要搅拌。

## 3. 麻辣烫（热煮）

- 需要热源。
- 水 + 汤底。
- 待定：

  - 食用效果。
