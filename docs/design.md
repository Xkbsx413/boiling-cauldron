# 沸鼎烟火 · 核心玩法设计记录

主题：麻辣烫 / 钵钵鸡
记录日期：2026-10-25

## 1. 底料与汤底（炒锅配方）

- 优先实现：通过森罗厨房的炒锅配方制作相关底料、汤底物品。
- 使用森罗的炒锅配方类型 `kaleidoscope_cookery:pot` 注册。
- 三种底料产物均为 1 个，且都是可手持物品。
- 状态：物品、配方、标签、纹理已实现。
- 配方：
  1. 菌菇底料 = 大蒜 x1 + 竹荪 x1 + 原版蘑菇标签 x2 + 油脂块 x1 → 菌菇底料 x1
  2. 麻辣底料 = 花椒 x1 + 森罗辣椒 x1 + 大蒜 x1 + 油脂块 x1 → 麻辣底料 x1
  3. 藤椒底料 = 花椒 x2 + 大蒜 x1 + 油脂块 x1 → 藤椒底料 x1
- 使用构想：1 个底料放入锅中提供 64 次浸泡额度（P2 已定稿）。
- 实现备注：
  - 油脂块使用 `kaleidoscope_cookery:oil_block`，并加入 `kaleidoscope_cookery:pot_ingredient` 标签，使其能作为炒锅配料放入。
  - 1 个油脂块由 9 个油脂合成；此外森罗炒锅开炒前仍需先抹 1 个液体油脂（`#kaleidoscope_cookery:oil`），这是锅的独立状态。
  - 森罗辣椒建议使用 `c:crops/chilipepper` 标签（红辣椒 / 青辣椒均可）。
  - 原版蘑菇标签 `boiling-cauldron:mushrooms` 包含红蘑菇和棕色蘑菇，配方中需要 2 个该标签材料。
  - 无容器的炒锅成品需要潜行并使用锅铲取出，底料沿用此机制。

## 2. 钵钵鸡（冷泡）

状态：已实现并通过 datagen；原料效果保留调整后待重新 build 和游戏测试（2026-11-01）。

### 2.1 容器与容量

- 容器方块：`bobo_chicken_pot`，带 BlockEntity。
- 容量：4×4，共 16 格；每格最多 1 个食物，不可堆叠。
- 每格独立 60 秒浸泡计时；移动或取出食物会清零该格进度，底料次数不返还。
- 进度条：绿色填充，完成时满条；GUI 每 10 tick 同步一次；区块卸载时暂停计时。
- GUI 采用原版槽位交互；不设碗，右键成品直接拿到光标。
- 第一版建议不接入漏斗等自动化，避免状态同步和复制问题。

### 2.2 水、底料与冲洗

- 容器初始状态为“空”。
- 手持水桶右键：加水，消耗水桶并返还空桶；状态变为“水”。
- 只有“水”状态且 16 格全空、底料计数为 0 时，才能放入 1 个底料：
  - 菌菇底料 `mushroom_base`
  - 麻辣底料 `mala_base`
  - 藤椒底料 `rattan_pepper_base`
- 放入底料消耗 1 个底料物品；底料类型全局唯一，底料计数设为 64。
- 每向空格放入 1 个食物，立即扣 1 次底料；取出或移动未完成食物不返还次数。
- 底料计数降到 0 时：
  - 状态显示“空”，水立即消失。
  - 已经扣过次数的食物继续浸泡到完成。
  - 必须等 16 格全部取空后，才能重新加水、再放新底料。
- 冲洗：
  - 条件：16 格全空、底料计数 > 0、容器内有水。
  - 手持水桶右键，消耗水桶并返还空桶。
  - 底料类型清空、底料计数归 0，水保留，状态回到“水”。
  - 因此可提前换底料，不必耗尽 64 次。
- 底料耗尽后水消失；已付费食物仍可完成，但取完后需重新加水才能继续。

### 2.3 成品与 NBT

- 成品统一为 1 个物品：`boiling-cauldron:bobo_chicken`。
- NBT：
  - `OriginalItem`：原料物品 ID，用于 tooltip。
  - `Flavors`：已浸泡底料列表，最多 3 个，允许值 `mushroom`、`mala`、`rattan_pepper`；同种底料不可重复。
- 显示名按固定顺序“菌香 → 辣辣 → 藤椒”组合，与浸泡顺序无关：
  - 1 种：菌香的钵钵鸡 / 辣辣的钵钵鸡 / 藤椒的钵钵鸡。
  - 2 种：菌香辣辣的钵钵鸡 / 菌香藤椒的钵钵鸡 / 辣辣藤椒的钵钵鸡。
  - 3 种：三味钵钵鸡；tooltip 列出菌香 / 辣辣 / 藤椒。
- 再次浸泡：
  - 成品可放回容器，继续增加口味。
  - 已有 3 种或同种底料时拒绝。
  - `OriginalItem` 保持不变，只追加 `Flavors`。
  - 未完成取出时进度清零，底料次数不返还。
- 标签 `#boiling-cauldron:bobo_chicken` 包含成品；口味由 NBT 区分，标签不能区分口味。
- 所有食物均可作为原料；原料 `FoodComponent` 自带的状态效果保留，特殊行为和容器返还仍不保留。
  - 金苹果、附魔金苹果、河豚等原料的状态效果按原概率、时长和等级保留。
  - 蘑菇煲、兔肉煲、蜂蜜瓶等吃完不返还容器。
  - 紫颂果传送、蜂蜜瓶解毒、迷之炖菜 NBT 效果等特殊行为不保留。

### 2.4 食用与效果

- 固定食物值：饱食度 8，饱和度修正值 0.55（实际约 8.8 点）。
- 食用时额外直接增加 2 点饱和度，只加一次；最终约 10.8 点，受当前饱食度上限限制。
- 再次浸泡不会额外增加食物值或这 2 点饱和度；每次食用按固定值结算。
- 底料效果：
  - 菌菇：生命恢复 I，30 秒。
  - 麻辣：力量 I，30 秒。
  - 藤椒：抗性提升 I，30 秒。
- 食用带多种口味的成品时，分别施加对应效果。
- 不叠加规则：
  - 已有同类效果剩余时间 < 30 秒：刷新到 30 秒。
  - 已有同类效果剩余时间 ≥ 30 秒：不处理。
  - 不延长总时长、不提升等级。
  - 若已有更高等级效果，不降级；仅在现有等级不高于本效果时刷新。
- 原料 `FoodComponent` 自带的状态效果保留；先应用原料效果，再应用底料效果；同种效果按底料不叠加规则处理。

### 2.5 破坏与边界

- 破坏容器：掉落容器方块和 16 格内所有食物。
  - 未完成：掉落原始食物。
  - 已完成：掉落对应 `bobo_chicken`（含 NBT）。
- 水、底料类型、底料计数、所有进度清零。
- 取出或移动未完成食物：该格进度清零，底料次数不返还；不额外提示。
- 多人同时操作时，服务端权威校验底料计数、格子状态和取出操作，避免复制。
- 第一版不实现竹签；后续可扩展串串玩法。
